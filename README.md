# Flappy Type

A small Flappy Bird-inspired typing game built with plain HTML, CSS, and JavaScript.

## Gameplay

- The current target word is shown on screen.
- Type that word three times in a row.
- Every correct letter nudges the bird upward.
- Wrong keys flash the current target red, so you can immediately keep typing the next correct key.
- When all three repetitions are complete, the game rotates to a new word from the local Google common-words list.
- The word-count slider selects the top 1,000 through 10,000 words in 1,000-word groups.
